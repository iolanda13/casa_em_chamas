# Herói das Chamas

Minijogo do curso de Introdução ao Desenvolvimento Web da trilha de Back-end ofertada pela FAPEMA.

**Situação**: você é um bombeiro e recebeu um alerta de incêndio em um domicílio.

Seu objetivo é chegar no cômodo certo para salvar a vítima das chamas.

## Como jogar

1. Abra o arquivo `index.html` no navegador.
2. O jogo começa na `rua`.
3. A cada rodada, leia sua localização atual e escolha uma das opções.
4. O jogo termina quando você chegar ao `segundo quarto` e salvar a pessoa.

Feito somente com HTML, usando âncoras (`#`) para navegar entre os cômodos.
